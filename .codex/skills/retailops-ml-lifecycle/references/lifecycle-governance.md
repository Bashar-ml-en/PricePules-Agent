# Lifecycle governance

Use immutable snapshots and historical-only features. Compare a declared
baseline before an eligible candidate on chronological validation; keep a locked
final test period. Register metrics, configuration, split dates, data and
feature versions, champion, and rollback target.

In production, track realised forecast error, data quality, coverage, feature
availability, drift, and reviewer outcomes. Retraining and rollback are
auditable proposals, not automatic side effects.
